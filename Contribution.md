# Contributing to Apress Source Code

Copyright for Apress source code belongs to the author(s). However, under fair use you are encouraged to fork and contribute minor corrections and updates for the benefit of the author(s) and other readers.

## How to contribute

1. Make sure you have a GitHub account.
2. Fork the repository for the relevant book:  
   [https://github.com/Apress/Applied-AI-with-LLMs](https://github.com/Apress/Applied-AI-with-LLMs)
3. Create a new branch on which to make your change, for example:

   ```bash
   git checkout -b my_code_contribution
   ```

4. Commit your change. Include a commit message that clearly describes the correction.  
   If the commit message is unclear, the correction will not be accepted.
5. Submit a pull request against the main repository.

Please keep contributions focused: bug fixes, dependency updates that restore the examples, typo fixes in comments/docs, and small clarity improvements are welcome. Large rewrites or unrelated new features are out of scope for this companion repository.

**Do not** include API keys, tokens, personal `.env` files, or other secrets in pull requests.

Thank you for your contribution!
